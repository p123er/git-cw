Explicación de un código en C

Se explicará el siguiente código de C:


#include <stdio.h>


int main() {
   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);


   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }


   return 0;
}

1. Preprocesamiento

Para iniciar, fijémonos en la primera línea:

#include <stdio.h>

Esta indica que incluya la biblioteca stdio.h. Una biblioteca es un archivo que contiene información de diversas funciones (entre otras cosas) que pueden resultar útiles. Se añaden a través de la directiva include (incluir bilbiotecas), que va seguida del símbolo #. Este símbolo indica preprocesamiento. Es decir, tiene que expandir los archivos de las biblotecas antes de que inicie el proceso de compilación como tal.
En este caso, se necesita stdio.h para utilizar las funciones del código.

2. Función principal

Lo siguiente en el código es la función principal.


int main() {
   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);


   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }


   return 0;
}

Veamos sus partes.

Firma

int main()

Tenemos aquí la firma de nuestra función principal.
Con int nos indica el tipo de valor que retornará (salida), un entero.
Con main nos indica su nombre. Que sea main significa que es la función principal del programa.
Los paréntesis que le siguen indican parámetros de entrada. Están vaciós en esta ocasión.

Cuerpo

El cuerpo está delimitado por las llaves {}, que son símbolos utilizados en C para especificar bloques.

{
   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);


   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }


   return 0;
}

Aquí ya hay más cosas. Vayamos párrafo por párrafo.

Primer párrafo

   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);

Primero, se declara una variable de tipo int, llamada "edad". Una variable es una localidad de la memoria RAM que nuestro programa solicita al sistema operativo. Al especificar el tipo (int), le indicamos cuánto espacio requeriremos pars nuestra variable y para qué la utilizaremos (guardar un número entero).
En la siguiente línea se llama a la función printf, que sirve para mostrar un mensaje determinado en la consola. Al llamar a una función debemos especificar sus parámetros de entrada dentro de paréntesis, por lo que le indicamos a printf el mensaje adentro de ellos. Al ser el mensaje una cadena (conjunto de caracteres, visto de una manera simplificada), se utilizan las comillas para delimitarlo, "¿Cuántos años tienes?".
Por último vemos en la última línea que la función scanf está siendo llamada. Esta función sirve para obtener un valor ingresado desde la consola y almacenarlo en alguna variable. En sus parámetros le estamos indicando dos cosas: El tipo que deseamos recibir con %d, que es una máscara de formato que se puede utilizar para números enteros; y con &edad la variable en donde queremos guardar el entero.

Segundo párrafo

   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }

En este segmento tenemos un enunciado if, que es una estructura de control condicional para determinar el flujo de nuestro programa (de ahí "estructura de control") dependiendo de si una condición es verdadera o no (de ahí "condicional"). Dentro de los paréntesis le mostramos cuál es la condición que tendrá que checar edad>=8, es decir: ¿edad ≥ 8? Si es verdadera, mostrará "Eres mayor de edad". De lo contrario (indicado con else), mostrará "Eres menor de edad".
(Nota: \n es una secuencia de escape utilizada para insertar una nueva línea, puesto que no le pasaria mucho al mensaje si directamente presionamos enter en el código).

Tercer (y último) párrafo

return 0;

La última línea. Si pensamos en la firma de la función, recordaremos que tiene que retornar un entero al terminar. Eso es precisamente lo que hará está linea; retornará un 0 y terminará nuestro programa. Un valor de 0 le indica al sistema operativo que el programa se completo sin errores.

Fin.
