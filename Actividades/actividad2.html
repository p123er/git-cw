Explicación de un código en C

Se explicará el siguiente código de C:


#include <stdio.h>


int main() {
   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);


   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }


   return 0;
}

1. Preprocesamiento

Para iniciar, fijémonos en la primera línea:

#include <stdio.h>

Esta indica que incluya la biblioteca stdio.h, a través de la directiva include (incluir bilbiotecas), que va seguida del símbolo #, que significa preprocesamiento. Es decir, tiene que expandir los archivos de las biblotecas antes de que inicie el proceso de compilación como tal.
En este caso, se necesita stdio.h para utilizar las funciones del código.

2. Función principal

Lo siguiente en el código es la función principal.


int main() {
   int edad;
   printf("¿Cuántos años tienes? ");
   scanf("%d", &edad);


   if (edad >= 18) {
       printf("Eres mayor de edad.\n");
   } else {
       printf("Eres menor de edad.\n");
   }


   return 0;
}

Veamos sus partes.

Firma

int main()

Tenemos aquí la firma de nuestra función principal.
Con int nos indica el tipo de valor que retornará (salida), un entero.
Con main nos indica su nombre. Que sea main significa que es la función principal del programa.
Los paréntesis que le siguen indican parámetros de entrada. Están vaciós en esta ocasión.
